# Реестр транзакций Saga-оркестрации

## Описание

Реестр транзакций для процесса обработки платежей в системе OrchestrPay. Включает списание средств, проверку антифрод-системой, перевод контрагенту и компенсационные механизмы.

## Таблица транзакций Saga

| Транзакция | Описание | Тип | Компенсация |
|-----------|----------|-----|-------------|
| CREATE_PAYMENT | Создание записи платежа в базе данных с начальным статусом PENDING | повторяемая | - |
| VALIDATE_PAYMENT_DATA | Валидация входных данных платежа (сумма, валюта, реквизиты) | повторяемая | - |
| RESERVE_USER_FUNDS | Резервирование (блокировка) средств на счете пользователя перед списанием | компенсируемая | RELEASE_RESERVED_FUNDS |
| DEBIT_USER_ACCOUNT | Фактическое списание денег со счёта пользователя | компенсируемая | REFUND_USER |
| FRAUD_CHECK_INTERNAL | Проверка транзакции по внутренним правилам антифрод-системы | повторяемая | - |
| FRAUD_CHECK_EXTERNAL | Проверка транзакции через внешних провайдеров (AML, GeoRisk и др.) | повторяемая | - |
| AWAIT_MANUAL_REVIEW | Ожидание решения оператора при назначении транзакции на ручную проверку (таймаут 20 минут) | повторяемая | - |
| APPLY_CUT_OFF_TIME | Применение правила автоматического одобрения при превышении cut-off времени | повторяемая | - |
| CREDIT_COUNTERPARTY | Перевод денег контрагенту (необратимая операция) | необратимая | - |
| UPDATE_PAYMENT_STATUS_SUCCESS | Обновление статуса платежа на SUCCESS в базе данных | повторяемая | - |
| UPDATE_PAYMENT_STATUS_FAILED | Обновление статуса платежа на FAILED в базе данных | повторяемая | - |
| UPDATE_PAYMENT_STATUS_REFUNDED | Обновление статуса платежа на REFUNDED после компенсации | повторяемая | - |
| NOTIFY_USER_SUCCESS | Отправка уведомления пользователю об успешном выполнении платежа | повторяемая | - |
| NOTIFY_USER_FAILURE | Отправка уведомления пользователю об отклонении платежа | повторяемая | - |
| NOTIFY_SECURITY_FRAUD | Отправка уведомления в систему безопасности при обнаружении подозрительной операции | повторяемая | - |
| NOTIFY_SUPPORT_ERROR | Отправка уведомления в службу поддержки при системной ошибке | повторяемая | - |
| RELEASE_RESERVED_FUNDS | Освобождение зарезервированных средств на счете пользователя (компенсация для RESERVE_USER_FUNDS) | повторяемая | - |
| REFUND_USER | Возврат списанных денег обратно на счет клиента (компенсация для DEBIT_USER_ACCOUNT) | повторяемая | - |
